# Calculator 🧮

A fast, lightweight **console-based calculator written in C**.  
It supports arithmetic operations like long expressions .. very long and it's kinda precise!

---

## ✨ Features

### Basic Arithmetic
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division

### Scientific Functions
- 📐 Sine (`sin`)
- 📐 Cosine (`cos`)
- 📐 Tangent (`tan`)
- √ Square root (`sqrt`)
- 🔢 Power (`pow`)
